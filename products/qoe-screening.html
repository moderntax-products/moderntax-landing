QoE Screening

Know which loans need a QoE before you order one.

SBA SOP 50 10 8 calls for a Quality of Earnings review on some loans and not others. Capture the loan amount at intake and screen every business order against the IRS transcripts already on file — one click, one verdict.

02
How it works

From order to answer.

  1. Capture the loan

    Add the loan amount and purpose when you place the verification order.

  2. Verify

    The Compliance Verification order pulls the business’s IRS transcripts.

  3. Screen

    Run the QoE check on the order and read the verdict and warnings.

  4. Engage if needed

    When a review is called for, talk to us about scoping a QoE engagement.

Partner API & MCP

IRS-of-record data, as an endpoint.

Embed compliance verification in your product: REST intake, webhook or polling delivery, structured JSON, a cross-reference check against borrower-stated figures, and an MCP server so AI agents can order and read results directly.

01
What you get

Built for platforms and the agents they run.

01

REST + webhooks

One POST creates an order; results arrive by signed webhook or polling, with idempotent request tokens.

02

Structured JSON

Filings with financials, transaction codes, balances and a compliance summary — alongside the PDF transcripts.

03

Cross-reference

Compare what a borrower stated against the IRS record and get the differences back as data.

04

MCP server

Model Context Protocol tools — verify, order, status, transcript data and cross-reference — for AI agents, on the same API key.

05

Sandbox

A work email gets an API key against synthetic taxpayers. Not every product is available in the sandbox; the API docs list what is.

06

Portal visibility

Every API order is also visible in the portal, so operations teams work the same record.

02
How it works

From order to answer.

  1. Get a sandbox key

    Sign up with a work email at the sandbox and get a key against synthetic data.

  2. Build against synthetic data

    Exercise the order flow against simulated taxpayers and IRS outcomes.

  3. Go live

    Production keys are provisioned with your agreement.

03
In code

One call to order. One URL for agents.

The full reference — authentication, ordering, polling, webhooks, errors and the MCP tool list — lives in the API docs.

# Create an order
curl -X POST https://portal.moderntax.io/api/intake/transcript \
  -H "x-api-key: $MT_KEY" \
  -d '{"request_token":"loan-4482","entities":[{"entity_name":"Atlas Roofing LLC",
       "tid":"88-1213417","form_type":"1120S","fiscal_year_end_month":12,
       "years":["2024","2023"]}]}'

# MCP: point your agent at
https://portal.moderntax.io/api/mcp   # Authorization: Bearer $MT_KEY

01 · Products

Two doors.
One record behind them.

A portal for the processors doing the closing, an API for the platforms doing the originating. An order placed through either one shows up in both — same artifacts, same audit trail.

For loan teams · the portal

Enter it once. Download a form that’s already filled out.

The 8821 comes back pre-populated from what you typed — taxpayer, TIN, address, form, years, our CAF — with only the signature line blank. It goes through your own closing process. We never contact your borrower.

  • Election status confirmed before we pull — included.
  • Your own spreadsheet columns — no template to reformat.
  • Per-processor billing breakdown for managers.
  • Rejections never billed · nothing re-pulls on its own.
See the order flow →
For platforms · the API

Verification as an endpoint, in your schema.

One POST creates a verification; a webhook returns parsed JSON, raw IRS HTML, and PDF — shaped to a schema you name. Every pull runs under a credentialed practitioner’s own CAF, so there’s no single credential to get flagged.

  • REST + webhooks · idempotency keys by contract.
  • Name your response schema — we version it.
  • API orders visible in the portal to underwriters.
  • Wholesale lane for resellers and LOS platforms.
